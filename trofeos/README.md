# Trofeos

Foto de cada entregable, **sin excepción, incluso los feos**. Es el único registro de progreso que importa.

## Nombre de archivo

```
NNN-AAAA-MM-DD-slug.jpg
```

- `NNN` — número de sesión, con ceros (`007`)
- `AAAA-MM-DD` — fecha de la sesión
- `slug` — dos o tres palabras en minúscula con guiones

Ejemplo: `012-2026-10-04-siluetas-negro.jpg`

Si una sesión deja más de un entregable: `012-2026-10-04-siluetas-negro-a.jpg`, `-b`, etc.

## Cómo se sube

**Desde Claude Code:** Claude mueve la foto acá y la commitea junto con la entrada de bitácora.

**Desde el celular:** github.com → esta carpeta → *Add file* → *Upload files*. Claude te pasa el nombre ya armado.

## Nota

El repo es **público**. Todo lo que se suba acá lo puede ver cualquiera. Si en algún momento eso pesa a la hora de subir un dibujo feo, el problema no es el dibujo: pasá el repo a privado. La regla de subir todo no se negocia, el repo sí.
